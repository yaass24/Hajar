# HAJAR | هَجَر

### Explore Al-Ahsa Through an Interactive 3D Adventure

HAJAR is an interactive 3D adventure game prototype inspired by the cultural heritage, landscapes, and landmarks of Al-Ahsa, Saudi Arabia.

The game invites players to explore a virtual world, discover iconic locations, interact with characters, and complete challenges inspired by the region's identity.

## 🎮 Play HAJAR

**[Launch the Game](https://hajar-landmark-quest.replit.app/)**

Experience HAJAR directly in your browser.
